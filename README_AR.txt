نسخة موقع زياد الشاوش - تحديث نهائي.

التعديلات المضافة:
- إصلاح ظهور شريط التنقل حتى لا يغطي الكاردات أو يظهر في منتصف التصميم.
- تفعيل الوضع الليلي والنهاري مع حفظ اختيار المستخدم في المتصفح.
- إضافة تموج ضوئي متحرك على حواف الكاردات بشكل هادئ.
- تفعيل الروابط المهمة: رابط الموقع، استعراض السيرة الذاتية CV، البريد، الهاتف، والموقع الجغرافي.
- تحسين استجابة التصميم على الشاشات المتوسطة والصغيرة.

طريقة التشغيل:
افتح ملف index.html مباشرة أو ارفع المجلد كما هو إلى Netlify / Vercel / GitHub Pages.
